# Portfolio

## Назначение

Публичная GitHub-витрина портфолио по AI automation и prompt engineering для анкеты на стажировку.

Проект не является продуктовым приложением. Его цель — аккуратно представить выбранные кейсы, компетенции, подход к задачам и ссылки на безопасно опубликованные материалы.

## Стек

- Markdown
- GitHub README
- Case studies в `cases/`
- Скриншоты и изображения в `assets/`

## Структура

```text
README.md                 главная страница портфолио
QUESTIONNAIRE.md          тексты для анкеты
PUBLISH_CHECKLIST.md      чеклист перед публикацией
PUBLIC_REPOS.md           карта отдельных публичных репозиториев
cases/TEMPLATE.md         шаблон описания кейса
assets/                   публичные изображения и скриншоты
.agents/SNAPSHOT.md       операционное состояние работы над портфолио
```

## Принятые решения

- Конкретные проекты для показа выбираются отдельно после обсуждения.
- Портфолио должно выглядеть как подборка практических кейсов, а не как список учебных упражнений.
- Каждый проект публикуется как отдельный clean repo; `Portfolio` только ссылается на них.
- Исходные рабочие папки не трогать и не публиковать напрямую.
- Публичные документы портфолио и clean repos вести на русском языке, если пользователь отдельно не попросит английскую версию.
- Не публиковать секреты, реальные `.env`, приватные базы, клиентские материалы и необезличенные скриншоты.
- Для каждого кейса использовать структуру: задача, решение, AI/prompting, стек, личный вклад, результат, ограничения, дальнейшие улучшения.

## Правила работы

- Не добавлять конкретный проект в README как кейс без отдельного решения пользователя.
- Перед публикацией проходить `PUBLISH_CHECKLIST.md`.
- При создании `AGENTS.md` / `CLAUDE.md` для clean repos делать их публичными sanitized-доками на русском, а не копией внутренних инструкций.
- Операционный статус хранить только в `.agents/SNAPSHOT.md`.
