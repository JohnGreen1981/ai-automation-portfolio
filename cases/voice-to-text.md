# Voice To Text

Компактный Telegram-бот для транскрибации аудио.

## Коротко

Voice To Text — Telegram-бот, который превращает голосовые сообщения и аудиофайлы в текст. После транскрибации пользователь может вручную запустить GPT-редактор одной кнопкой.

## Проблема

Голосовые сообщения удобны для записи мыслей, но неудобны для дальнейшей работы: их сложно искать, копировать, редактировать и вставлять в документы.

Нужен простой workflow:

- отправил голосовое;
- получил текст;
- при необходимости нажал "отредактировать";
- скопировал результат.

## Решение

Бот принимает голосовые и аудиофайлы, отправляет их в speech-to-text API и возвращает расшифровку. Редактор не включён глобально: пользователь сам решает, нужно ли применять литературную правку к конкретной транскрипции.

## Роль AI / Prompt Engineering

- AssemblyAI используется для speech-to-text.
- GPT-редактор применяется только по запросу пользователя.
- Промпт редактора должен исправлять текст, не меняя смысл.
- Разделение "сырой transcript" и "edited transcript" сохраняет контроль пользователя.
