# Meeting Secretary

Бот для расшифровки встреч и подготовки summary.

## Коротко

Meeting Secretary — Telegram-бот, который принимает аудио, видео или файл с записью встречи, расшифровывает её, делит по спикерам и готовит краткое summary. Проект закрывает реальный сценарий: быстро получить полную стенограмму и рабочую выжимку после созвона.

## Проблема

После встреч часто остаётся длинная запись, которую никто не хочет переслушивать. Нужно быстро получить:

- полную стенограмму;
- разбивку по спикерам;
- краткое содержание;
- решения;
- поручения;
- открытые вопросы;
- риски и следующий шаг.

Обычная транскрибация не решает задачу полностью: длинные файлы упираются в лимиты Telegram, а summary длинной встречи может потерять середину.

## Решение

Бот принимает `voice`, `audio`, `video`, `video_note` и документы. Запись отправляется в AssemblyAI, результат возвращается пользователю файлом `.txt`.

Для больших файлов предусмотрена архитектура с Telegram Local Bot API. Для длинных стенограмм используется chunked summary pipeline: сначала summary по последовательным чанкам, затем финальная сборка.

## Роль AI / Prompt Engineering

- AssemblyAI делает speech-to-text и diarization.
- GPT-слой пытается определить имена и роли спикеров по контексту.
- GPT summary строится по структуре: кратко, решения, поручения, открытые вопросы, риски, следующий шаг.
- Для длинных встреч используется chunking, чтобы не опираться только на начало и конец записи.
- Модель не должна придумывать спикеров при низкой уверенности: остаются нейтральные метки.

## Результат

Бот стабильно работает на VPS и принимает большие записи через Local Bot API. Пользователь получает файл со стенограммой и отдельное GPT-summary в рабочем формате.

## Ограничения и безопасность

- Нельзя публиковать реальные записи, стенограммы, имена участников и логи.
- Рабочие `.env` и VPS-настройки не публикуются.
- Summary может ошибаться, поэтому важные решения нужно проверять по стенограмме.
- Clean repo должен содержать только код и синтетические/обезличенные примеры.
