# Oleg Psychologist

AI-бот с долгосрочной памятью для личных психологических сессий.

## Коротко

Oleg Psychologist — чувствительный AI-кейс про персонального бота с долгосрочной памятью. Для портфолио он подходит не как полный публичный код, а как обезличенный architectural case study или demo repo с синтетическими данными.

## Проблема

Обычный чат с LLM не помнит долгую историю пользователя. Для персонального помощника важны:

- память прошлых сессий;
- поиск релевантных воспоминаний;
- обновляемый профиль пользователя;
- аккуратные границы роли;
- поддержка голосового ввода.

В чувствительной теме нельзя просто хранить и публиковать всё подряд.

## Решение

Архитектура строится вокруг нескольких слоёв:

- Telegram bot как интерфейс;
- FastAPI/webhook слой;
- in-memory сессионный буфер;
- Supabase pgvector для долгосрочной памяти;
- embeddings для поиска релевантных прошлых сессий;
- отдельное обновление профиля пользователя;
- speech-to-text для голосовых сообщений.

## Роль AI / Prompt Engineering

- Системный промпт задаёт рамку поведения и границы темы.
- LLM получает текущий буфер, релевантные воспоминания и профиль пользователя.
- Отдельный LLM-вызов обновляет краткий профиль после сохранения сессии.
- Важная часть prompt engineering — не только "что сказать", но и как не выходить за роль.

## Стек

## Результат

Проект показывает важный AI-agent паттерн: персональный ассистент не должен быть просто stateless chat. Ему нужен controlled memory layer, профиль, правила сохранения и осторожная работа с приватностью.

Для GitHub подготовлен не production dump, а безопасный demo repo: синтетическая реализация session buffer, memory search, profile facts, prompt context и safety boundaries без реальных сессий и deployment-деталей.

## Ограничения и безопасность

- Тема психологических сессий чувствительна.
- Нельзя публиковать реальные сессии, профиль, промпты с личными фактами, owner ID и production-настройки.
- Для GitHub подготовлено демо на синтетических данных вместо полного рабочего проекта.
- Нужно явно указать, что бот не является медицинской или психотерапевтической услугой.
