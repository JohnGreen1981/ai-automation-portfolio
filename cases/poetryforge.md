# PoetryForge

CLI-валидатор метра и рифмы для LLM-generated русской поэзии.

## Коротко

PoetryForge — developer tool для проверки русской силлаботоники. Он используется как внешний валидатор: LLM генерирует стихотворение, инструмент проверяет метр и рифму, затем LLM исправляет проблемные строки.

## Проблема

LLM может хорошо имитировать стиль, но плохо контролирует слоги, ударения, метр и рифму. Для русской поэзии это особенно заметно: токены модели не совпадают со слогами, а информация об ударениях не всегда доступна.

Нужен инструмент, который даёт модели внешний feedback loop:

- где сбился метр;
- где неверное количество слогов;
- какая рифма слабая;
- какие омографы нужно разобрать по контексту.

## Решение

PoetryForge работает как CLI и Python API:

- анализирует строки и стихотворения;
- проверяет регулярные и нерегулярные метры;
- определяет ударения;
- проверяет рифмы;
- подбирает рифмы;
- строит рифменные схемы.

Главный workflow: generate -> validate -> fix -> validate again.

## Роль AI / Prompt Engineering

- LLM не получает слепое доверие на поэтическую форму.
- Инструмент возвращает issues, которые модель использует для исправления.
- Промпт генерации опирается на внешний валидатор, а не только на внутреннее ощущение модели.
- Это пример связки "LLM + deterministic checker".
